# Friendly Geram — نسخه توسعه‌یافته

پیام‌رسان خصوصی و دعوت‌محور با Node.js، Express، Socket.IO و SQLite. این نسخه امکانات گروه و کانال متنی، لینک دعوت، تنظیم نام/عکس پروفایل، انتخاب زبان فارسی/انگلیسی، تم روشن/تیره، پاسخ/ویرایش/حذف/واکنش/سنجاق پیام و ابزار ساخت GIF از چند تصویر را دارد.

## پیش‌نیازها
- Windows 10/11
- Node.js 20 یا جدیدتر (نسخه LTS پیشنهاد می‌شود)
- اینترنت برای نصب بسته‌ها و بارگذاری کتابخانهٔ ساخت GIF از CDN

## اجرا در ویندوز
1. ZIP را در پوشه‌ای مانند `C:\Friendly-Geram` استخراج کن.
2. PowerShell را در همان پوشه باز کن.
3. اجرا کن:

```powershell
npm install
npm start
```

4. مرورگر را در `http://localhost:3000` باز کن. حساب مدیر اولیه از `.env` همین بسته ساخته می‌شود، اگر نام کاربری آن از قبل در دیتابیس نباشد. اگر دیتابیس قدیمی داری، فایل `data/friendly-geram.sqlite` را حذف نکن.

## قابلیت‌ها و محدودیت‌ها
- ثبت‌نام عمومی غیرفعال است؛ مدیر از پنل مدیریت حساب می‌سازد.
- گروه‌ها و کانال‌های متنی قابل ساخت‌اند. لینک دعوت را از داخل گروه/کانال کپی کن؛ عضو جدید باید وارد حسابش شود و لینک را باز کند.
- در کانال، فقط سازنده/مدیر می‌تواند پیام بفرستد.
- ویرایش و حذف پیام در گروه/کانال و گفت‌وگوی خصوصی، واکنش ایموجی، پاسخ و سنجاق وجود دارد. سنجاق در گروه/کانال فقط برای مدیران است.
- عکس پروفایل در این نسخه به صورت تصویر انتخابی و در دیتابیس ذخیره می‌شود؛ اندازهٔ عکس باید کوچک باشد.
- ابزار GIF چند تصویر انتخاب‌شده را به GIF متحرک قابل دانلود تبدیل می‌کند. برای این ابزار کتابخانهٔ gifshot از jsDelivr بارگذاری می‌شود؛ اگر CDN مسدود باشد، ساخت GIF در دسترس نیست.
- این نسخه هنوز تماس گروهی، ارسال مستقیم فایل/ویدیو/صوت در چت، کانال‌های پیشرفته، مدیریت نقش‌های کامل، رمزنگاری سرتاسری (E2EE)، تغییر رمز عبور و احراز هویت دومرحله‌ای ندارد. تماس گروهی در نسخه قبلی/فعلی نباید قابلیت تولیدی تلقی شود.
- پیام‌ها رمزنگاری سرتاسری ندارند. مدیر سرور می‌تواند پیام‌های ذخیره‌شده را بخواند؛ این موضوع را به کاربران اطلاع بده.
- پیام‌ها در `data/friendly-geram.sqlite` ذخیره می‌شوند. از کل پوشه `data` نسخهٔ پشتیبان بگیر.
- برای انتشار عمومی، HTTPS و بررسی امنیتی لازم است. هرگز `.env` یا پوشهٔ `data` را عمومی منتشر نکن. پیش از انتشار، رمز مدیر و `SESSION_SECRET` را عوض کن.
- تغییر `ADMIN_PASSWORD` در `.env` رمز حساب مدیری را که قبلاً در دیتابیس ساخته شده خودکار تغییر نمی‌دهد.

## عیب‌یابی
- اگر `SESSION_SECRET must be set` دیدی، `.env` را بررسی کن.
- اگر نصب `better-sqlite3` شکست خورد، Node.js LTS را نصب و `npm install` را دوباره اجرا کن؛ در برخی سیستم‌ها Build Tools ویندوز لازم است.
- اگر پورت 3000 اشغال بود، `PORT=3001` را در `.env` بگذار.
